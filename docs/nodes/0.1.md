# Node 0.1: Build and repo discipline

Roadmap "Done when": a fresh clone builds and tests in one command; CI runs on every commit; build and scratch folders auto-prune and never eat into the 20 GB reserve.

## CI half: what exists

`.github/workflows/ci.yml` builds and tests the `crates/broadsword` crate on every push (all branches) and every pull request. It has no secrets, no deploy steps and no third-party action except `actions/checkout`, pinned to a full commit SHA. The repo pins no Rust toolchain (no `rust-toolchain` file), so the job uses the stable toolchain preinstalled on the runner. The crate has no dependencies, so nothing is downloaded beyond the toolchain; `--locked` makes the build fail if `Cargo.lock` is out of date.

### CI contract

`python -I -B scripts/check_ci_workflow.py` fails if the workflow drifts from these lines (change both together):

- ci-triggers: push, pull_request
- ci-runner: windows-latest
- ci-build: cargo build --locked -p broadsword
- ci-test: cargo test --locked -p broadsword
- ci-checkout: actions/checkout pinned to a 40-character commit SHA, and no other `uses:` line

The `ci-checkout` line is documentation only: the checker enforces that rule in code (only `actions/checkout`, pinned to a 40-character SHA), and only checks that the line exists.

The checker also fails if the workflow limits any trigger with `branches`, `branches-ignore`, `tags`, `tags-ignore`, `paths` or `paths-ignore`, mentions `secrets.`, or has a `run:` line other than the build and test commands.

It reads block-style YAML line by line and fails closed on anything it cannot read that way: flow-style `{...}` or `[...]` (the only exception is a flat `on: [push, pull_request]` list), YAML anchors, aliases and merge keys, quoted keys, document markers (`---`, `...`, so multi-document files), more than one top-level `on:`, and, inside `steps:`, any quoted value that does not close on its own line or continues onto a deeper-indented line (`unrecognised form`).

The runner is Windows because the crate has Windows-only code (`#[cfg(windows)]` in `crates/broadsword/src/buildsrc.rs`).
