All numeric budgets below are **draft engineering proposals for Lazlo**,

**1. Infrastructure and rejection inventory (T1-T3).**
```check c1
build/bin/broadsword.exe test texture-author > scratch/n38-c1.txt 2>&1
PASS: contains test acceptance_inventory_and_rejections ... ok
```
Require settings coverage, fixture hashes/licences and direct library-entry
rejection tests from section 5. Exact inventory equality is the rule: this
prevents a suite that silently omits a baker or fixture from passing.

**2. A 3D stroke reaches the correct surface texels (T4).**
```check c2
build/bin/broadsword.exe test texture-author > scratch/n38-c2.txt 2>&1
PASS: contains test mesh_stroke_projection_and_undo ... ok
```
Frozen camera/ray/dab replays must paint the intended visible UV islands,
cross a UV seam without a gap, leave occluded/back-facing surfaces untouched,
and undo to byte-identical source tiles. Exact texel ownership/ID and
unchanged-tile equality apply; continuous dab values use T3's independently
derived arithmetic budget, not a tolerance fitted to candidate output.

**3. Layers and procedural wear masks remain editable (T5).**
```check c3
build/bin/broadsword.exe test texture-author > scratch/n38-c3.txt 2>&1
PASS: contains test layered_pbr_and_wear_reference ... ok
```
Compare each PBR channel and curvature/AO-driven seeded wear mask with
independent scalar reference tables. Layer reorder, mask edit, disable,
save/reload and undo must have their specified effects without changing
source bakes. Exact IDs/seeds/serialization round trips; numeric channel
error uses T3's operation-count-derived budget within the approved band.

**4. High-to-low tangent-space normal bake is clean (T6).**
```check c4
build/bin/broadsword.exe test texture-author > scratch/n38-c4.txt 2>&1
PASS: contains test high_low_normal_reference_and_seams ... ok
```
For every intended interior texel require a finite, normalized decoded
normal and a valid high-mesh hit, with no unexpected cage misses or
wrong-surface hits. Compare with analytic or independent reference normals:
maximum angular error at most **2 degrees**, including paired seam samples
after transformation into the same object frame. Reason: a tight first-cut
directional budget allowing texture quantization/interpolation, but not a
flipped tangent axis. T3 fixes the encoding, denominator/normalization
guards and seam sampling before baking; no post-failure pixel exclusions.
Padding must fill the configured dilation band without leaking another
island. Human inspection in c8 also checks grazing/specular views.

**5. All auxiliary baker contracts are implemented (T7).**
```check c5
build/bin/broadsword.exe test texture-author > scratch/n38-c5.txt 2>&1
PASS: contains test auxiliary_bakers_reference ... ok
```
Require normal, AO, signed curvature, thickness and ID entries in the
inventory. ID is exact; plane curvature is exactly zero in the analytic
case. Sphere curvature and closed-slab thickness use T3's scale-aware
arithmetic budgets. AO uses a frozen deterministic direction set and an
independently evaluated visibility reference; its budget includes the
reference's documented integration error. T7 initially creates failing
behavioural tests, not ignored tests or pretend implementations.

**6. Export a real smart-material wear pass (T8).**
```check c6
build/bin/broadsword.exe run texture-author -- cargo run --offline --release --example export_wear > scratch/n38-c6.txt 2>&1
PASS: contains export_wear: ok
```
The example evaluates the layered recipe against the high/low fixture's
bakes, exports mesh/material/textures plus a complete versioned manifest
to the configured root-relative scratch destination, then independently
decodes and checks the written files. Exact channel assignments, schema
version, UV set, tangent convention, hashes and case inventory are required.
Wear must differ from the pristine material on the prescribed nonempty
mask, and remain unchanged outside it within T3's arithmetic budget.
Round-trip equality alone is insufficient; compare decoded channel values
against T3's independent wear expectations.

**7. The actual Broadsword engine consumes that export (GPU; T9).**
```check c7
build/bin/broadsword.exe run render -- cargo run --offline --release --example material_ingest > scratch/n38-c7.txt 2>&1
PASS: contains material_ingest: ok
```
Run after c6. No hand editing, rebaking, repacking or second local imitation
of the engine shader is permitted. The engine loads the exact manifest and
images, checks hashes/semantics, renders the asset and channel-diagnostic
swatches through its real material pipeline, and saves captures/metrics.
For frozen scene-linear diagnostic swatches require RGB RMSE at most
**0.02**, maximum absolute channel error at most **0.05**, versus T3's
independent analytic expectations. Reasons: provisional allowances for
texture sampling/rasterization, with an absolute bound to catch localized
packing mistakes that an average hides. These are not perceptual claims.
Freeze lighting, exposure, interior masks and color transforms; do not
compare tone-mapped screenshots with linear references. Require exact
material-slot/UV/channel identity as well as the image comparison.

**8. Lazlo accepts the workflow and rendered result (human; T10).**
```check c8
build/bin/broadsword.exe run texture-author -- cargo run --offline --release --example paint_session > scratch/n38-c8.txt 2>&1
PASS: (human) Lazlo accepts a clean high-to-low normal bake and a smart-material wear pass exported straight into the Broadsword engine, under docs/ACCEPTANCE.md.
```
Needs an interactive desktop and Lazlo. Paint directly on the displayed
mesh, cross a seam, edit a layer/mask and undo; inspect the normal bake under
rotating light, then the unmodified exported asset in the real engine using
c7's manifest. Save actions, before/after images and Lazlo's explicit words
with the artifact identity. Program success produces evidence, not approval.
T10's minimal example is not a complete editor. **No timing acceptance
threshold or quiet-board check is proposed**; any later latency/throughput
claim needs its own quiet-board benchmark brief and approved budget.

## 2. Home

Proposal under accepted `docs/adr/0001-shared-core.md` option (a): a separate
registered repo `texture-author`, one Rust crate `texture-author`, with
headless bake/material APIs and a thin interaction example. File formats
are the contract with raster, brush, mesh and renderer repos.
**No Cargo dependency (path or git) on another repo without a new ADR,
which is Lazlo's call. Never plan a link into `projects/foundation`.**
No source includes, patch tables or generated links may bypass that rule.

Exchange versioned meshes (positions, indexed triangles, units, UVs,
normals, tangents, material IDs), stroke/dab recordings, tile/layer data and
material bundles. Export contract should use an approved glTF-compatible
metallic/roughness subset with explicitly specified texture packing and
normal orientation; unsupported fields fail, never disappear silently.
Native editable layers need their own versioned recipe alongside, not an
assumption that glTF stores editing history.

Actually reusing the 2.1 tile store, 2.2 brush evaluator or 2.3 mesh library
in-process requires a new ADR before implementation. ADR 0001 trigger 2
is relevant: a third Rust project needs the same math/parser; trigger 3
applies if a copied implementation shares a discovered bug. Do not copy
entire engines merely to avoid the decision. Replay/file adapters support
isolated tests, not a claim to deliver live shared-data editing.
`docs/adr/0004-roadmap-repo-map.md` proposes a workload workspace/shared
core and switchable groups, but is **Proposed**, not permission to import
another repo. Lazlo must resolve live UI/core reuse before T4/T10; if a
workspace is approved, rewrite this plan's homes/claims/commands first.
The engine half T9 is a separate repo task, exchanging artifacts only.

## 4. External needs

Every non-std need is a **decision for Lazlo**, not an approved dependency.
`docs/adr/0003-dependency-policy.md` is still Proposed.

- Prefer vetted, pinned, vendored Rust crates: candidates `serde`/`toml`
  for settings/manifests, `png` and `gltf` for interchange, and `proptest`
  for property generation. Verify versions, transitive licences, offline
  sources and actual need first. Until approved, keep harness fixtures in
  simple owned text encodings; no silent download during tests.
- GPU/window access comes through approved 2.5/input interfaces; introducing
  `wgpu`/`winit` or a new backend is a separate Lazlo decision. CPU baker
  tests should remain headless. GPU import/display checks fail when no
  compatible adapter exists, not skip.
- MikkTSpace's C implementation, Embree or a commercial baker SDK would be
  C/C++ exceptions requiring Lazlo. Prefer an independently tested Rust
  implementation of the agreed tangent convention and CPU ray queries;
  interoperability is still mandatory. No native library is assumed.
- **Graphics-heavy work:** the PC shares memory between system RAM and GPU.
  Lazlo moves this workload first and approves texture/mesh/ray residency
  limits before full-size runs. Initial analytic fixtures must be small.
- Mouse plus display suffice for baseline c8; pressure/tilt coverage needs
  Lazlo's tablet and an approved input path. No gamepad, audio interface or
  second PC is required. A second PC is optional, not an acceptance gate.
- Network access is only for separately approved dependency/reference
  acquisition. Record asset-specific licences and hashes, then run offline.
  No paid tools, credentials or external texture packs are required.

## 5. Test harness

T1 establishes module boundaries without fake success bodies.
T2 owns ordinary Rust tests, configuration, inventory validation and evidence
plumbing; validation is at shared public constructors used by every test,
example and eventual UI path. Required workload keys cover input/output
roots, mesh/texture/recipe limits, numeric scale band, projection/cage and
padding policies, work/ray/sample caps, seeds, timeouts and the acceptance
budgets in section 1. Settings tests deliberately change each consumed
budget and require the decision/output to change. Resolve paths from an
explicit configured root, not a parent-directory guess in a worktree.
Required proposed keys include `root`, `fixture_manifest`, `reference_data`,
`export_root`, `capture_root`, `max_mesh_bytes`, `max_triangles`,
`max_texture_pixels`, `max_recipe_nodes`, `max_resident_bytes`,
`coordinate_min_scale`, `coordinate_max_scale`, `cage_distance`,
`padding_texels`, `ray_limit`, `sample_count`, `seed`,
`acceptance_timeout_seconds`, `normal_max_angle_degrees`,
`channel_abs_tolerance`, `curvature_abs_tolerance`,
`thickness_abs_tolerance`, `ao_abs_tolerance`, `engine_rgb_rmse_max` and
`engine_channel_abs_max`. T2 must add any further required band/limit
keys before their consumers land. Configuration edits are outside this
documentation-only task's claim.

Reject invalid signs, NaN/inf, zero/degenerate frames, overflowing products,
empty fixtures/masks, duplicate/unknown fields, unsupported schema versions,
invalid indices/UVs, ambiguous overlapping UV islands and impossible cages
with named errors. Define permitted mirrored islands and tangent handedness
explicitly; test them. Bound sizes before allocation, arithmetic and ray
loops. Check finiteness of computed values before applying tile/state edits.
Test the smallest/largest valid coordinates and nearly cancelling values
against independent higher-precision reference data; reject values outside
the approved numeric band rather than accept subnormal underflow silently.

Exercise huge and truncated inputs, duplicate manifests, comments/strings
that resemble fields, CR/line breaks, Windows drive/backslash paths,
traversal and links replacing artifact paths during export. Artifact writes
must stay within configured scratch, not overwrite existing work, and
publish a success manifest only after all files/hashes are complete.
Inject a mid-write failure: preserve the first error and report incomplete
output without making it consumable. Cap child output and execution if a
viewer/engine process is spawned; include a descendant holding pipes open.
No shell-built commands or swallowed child failures.
Concurrent exporters must key any reservation/lock by the resolved output
directory, not the project label, and fail safely on collision. Tests must
exercise competing writers for that same directory; no stale-lock takeover.

T3's original fixtures: UV plane/cube with hard seams and material IDs,
mirrored tangent islands, high smooth sphere over a low triangulated sphere,
thin closed slabs, occluding corner, separated shells, and a chipped
painted-metal coupon. Include frozen dab/camera replays, layered channel
tables, procedural mask seeds, normal/seam expectations and export swatches.
Analytic sphere normals/curvature, slab thickness and independent visibility
integration are the reference, not the candidate baker. Independent
higher-precision calculations must document numeric budgets and the exact
curvature definition (signed mean curvature, with orientation specified).
Freeze intended coverage, boundary/seam masks and reference uncertainty.

Tests map directly to c1-c7: inventory/rejections, ray/dab property cases,
scalar layer golden tables and round trips, normal angular comparisons,
auxiliary reference values, decoded export values, then genuine engine
captures. Record case counts, worst errors, fixture/config hashes, revision,
GPU adapter and actual artifact paths. c8 adds the human workflow evidence.

Each owning brief includes a behavioural negative control: disable occlusion
and detect paint on the hidden shell; drop a layer and detect channel error;
invert the normal green channel and fail c4; return constant AO/thickness
and fail c5; swap roughness/metallic on export and fail c6/c7. Truncate a
manifest and require rejection before rendering. A missing-test compile
failure is not the control. Restore mutations and reread the intended diff.

## 8. Risks and size

The live shared-core product intent and accepted separate-repo ADR may
force a home rewrite. Unfinished tile/brush/mesh/engine APIs can block more
than bake math. Tangent convention, mirrored UVs, cage intersections,
open-surface thickness, curvature definition, color spaces and texture
packing can invalidate apparent visual agreement. Keep open surfaces out
of the closed-thickness contract with an explicit named rejection, not
fabricated zero thickness. Independent references and licensed assets
remain gates, not assumed available resources.

Shared GPU/RAM pressure, reference error, high polygon counts and a real
tablet/display adapter may expand the work. Full UV generation, arbitrary
shader graphs, UDIM workflows and commercial-material parity are not
promised; freeze the supported subset before checks run. Layered PBR,
procedural masks, 3D painting and every listed baker remain in scope even
though a normal bake alone would satisfy only part of the Done-when.

Rough implementation estimate: **20-35 small briefs**, not a measured
derived count. The first briefs above establish contracts and initial paths;
remaining work includes separate AO, curvature, thickness and ID
implementations, cage/acceleration refinements, texture encoding adapters,
editing/persistence operations, hostile-export handling and any missing
engine/display service slices. Re-scope before any slice exceeds the size
target; do not shrink acceptance to fit an optimistic estimate.

Close only when **a high-to-low normal map bakes cleanly; a smart-material
wear pass exports straight into the Broadsword engine**, supported by all
mechanical evidence and Lazlo's explicit verdict. No node status is changed
or claimed here.
