Roadmap "Done when": save/load round-trip is byte-identical; an old-version file still loads after a schema change. Status: in progress.

## What is there

- The binary encoding is canonical: every value has one byte form and the decoder accepts only that form. `tests/serial_binary.rs` tests the byte-identical round trip.
- `tests/serial_migrate.rs` and the committed v1 fixture under `tests/data/` cover loading an old-version file through the migration steps; the fixture is read and never written.

## What is left

- No `tag:` item exists, so the row stays `in progress`.
- Limits the doc states: the encoder does not check the depth limit that the decoder enforces; only `i64` integers.
