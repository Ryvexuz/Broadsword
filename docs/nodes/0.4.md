## Speedup

`examples/speedup.rs` runs 4096 items of ALU-only work for 1 to 32 workers. The coder's run in `jobs.md` (2026-11-20, 32 logical cores, a busy board) shows speedup 15.44 and efficiency 0.965 at 16 workers, and prints `PASS: efficiency at 16 workers >= 0.75`. At 32 workers efficiency is 0.688, which the doc attributes to 32 workers on 16 cores with SMT.

The doc's "Quiet-board run (done check 2)" section reads "To be recorded by the orchestrator", so the quiet-board run is not recorded yet.
