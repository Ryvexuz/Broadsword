## Benchmarks versus the naive version

Each structure is tested for equality with a brute-force answer, and the bench examples print a ratio against the naive scan. The figures below are quoted from the docs; the BVH doc says some of its runs had CPU at 99% from other jobs, so they are not quiet-board numbers.

- Octree: 112.730x (`docs/octree.md`, example `bench_octree`).
- BVH, closest hit: 74.431x; any hit: 90.481x (`docs/bvh.md`, example `bench_bvh`).
- Spatial hash: `examples/bench_spatial.rs` exists; read `docs/spatial_hash.md` for its figures.

## Leaks and sanitizers

Slot map and arena tests use a counting allocator and assert allocations equal frees. Sanitizers were not run: `slotmap.md` records that AddressSanitizer and Miri need a nightly toolchain, nothing was installed, and it asks Lazlo whether to add one. Until a sanitizer pass is recorded, the "zero leaks under sanitizers" half of the done-when is not met.
