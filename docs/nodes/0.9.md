# Node 0.9: Logging, tracing, test harness

Roadmap "Done when": one frame's timings open in a trace viewer; golden-image tests flag regressions. Status: in progress.

## What is there

- Golden-image tests: `projects/render/tests/golden.rs` (render repo commit `30c92c4`).
- Job logs: `crates/broadsword/src/job.rs`.
- Tracing: `foundation::trace` in `projects/foundation` (merged commit `3d7254b`, doc `projects/foundation/docs/trace.md`). Scoped spans go into per-thread buffers, and `write_chrome_json` writes the Chrome Trace Event JSON format. A span costs one relaxed atomic load when tracing is off; `examples/trace_overhead.rs` (commit `076f217`) measured the disabled span at about 10.9x to 13.4x an empty loop over four noisy runs (CPU 90 to 100%, so not a quiet-board figure), per the doc.

## What is left

- No recorded run shows a frame's timings opened in a trace viewer. The Chrome JSON export exists and is tested, but nobody has opened a file in a viewer and written it down.
- Structured logging: `foundation` has no logging module (see its `src/lib.rs`).
- Trace buffers are unbounded until `clear()`, and there is one collector per process (the doc's known limits).
- No `tag:` item exists, so the row stays `in progress`.
