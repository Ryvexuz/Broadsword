## What is there

Reference-value unit tests exist for each module (`tests/vec.rs`, `mat.rs`, `quat.rs`, `transform.rs`, `aabb.rs`, `intersect.rs` in the foundation repo), and the seeded fuzz in `tests/identities.rs` covers the inverse and compose identities, with the per-identity tolerances and mutation checks written in `identities.md`.
